# Security

Use [GitHub's private vulnerability reporting](https://github.com/rvr31/screenswitch/security/advisories/new) to report a security issue. Include the app version, macOS version, steps to reproduce, and the expected and actual behavior. Keep credentials and private keys out of reports.

Security fixes target the latest release. Install releases from this repository; official releases are signed with a Developer ID and notarized by Apple.

ScreenSwitch changes display settings through private macOS APIs. These APIs can change between macOS versions. Save your work before testing display changes.
